# Snake Game

A responsive Snake game built with React and TypeScript, featuring score tracking, high scores, collision detection, dynamic food spawning, and custom game styling.

## Features

- Arrow key movement
- Dynamic snake growth
- Random food spawning
- Food never spawns on the snake
- Wall collision detection
- Self-collision detection
- Current score tracking
- High score saved with localStorage
- Start game screen
- Game over screen
- Win screen when the board is completely filled
- Custom checkerboard design
- Responsive game layout
- Snake head with directional eyes

## Built With

- React
- TypeScript
- Vite
- CSS
- ESLint
- localStorage

## How to Play

- Press the Start Game button.
- Use the arrow keys to control the snake.
- Eat apples to grow and increase your score.
- Avoid hitting the walls or the snake's body.
- Fill the entire board to win the game.

## Controls

- ↑ Move Up
- ↓ Move Down
- ← Move Left
- → Move Right

## High Score

The highest score is saved in the browser using localStorage, so it remains available after refreshing or reopening the game.
